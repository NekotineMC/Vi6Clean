### Task 5: Fix Non-Thread-Safe Singleton Initialization
**Files:** ~15 StatusFlag and StatusEffectType classes
**Effort:** Quick (30 minutes)

**Issue:** Lazy initialization pattern is not thread-safe.

**Current pattern:**
```java
private static EmpStatusFlag instance;
public static final EmpStatusFlag get() {
    if (instance == null) {
        instance = new EmpStatusFlag();
    }
    return instance;
}
```

**Fix — Eager initialization:**
```java
private static final EmpStatusFlag INSTANCE = new EmpStatusFlag();
public static final EmpStatusFlag get() {
    return INSTANCE;
}
```

**Acceptance criteria:**
- [ ] All singletons use eager initialization
- [ ] No null checks needed
- [ ] Build passes
